# FurkanAl

Modüler 7 ajanlı AI asistanı için güvenli başlangıç mimarisi.

## Başlatma
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

API: http://127.0.0.1:8000
Swagger: http://127.0.0.1:8000/docs

Bu sürüm bir güvenli mimari iskeletidir. Gerçek LLM/web/browser/device entegrasyonları adapter olarak bağlanabilir.
